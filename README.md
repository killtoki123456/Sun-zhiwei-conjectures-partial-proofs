# Sun-zhiwei-conjectures-partial-proofs
关于孙智伟数学猜想的证明稿与部分结果。相关论证可能尚未经独立核验。

本仓库整理了本人得到的关于孙智伟（Zhi-Wei Sun）教授所提出数学猜想的证明稿、部分证明以及相关研究结果。
本仓库的主要目的，是将这些论证公开，方便数学研究者进行检查、讨论和进一步研究。
本仓库中的证明目前尚未经过独立的数学专家完整核验，我也只能看懂一部分。

这些论证的探索、推导、整理和表述过程中得到了 GPT 等人工智能工具的大量协助。作者本人目前也无法独立确认其中每一个技术步骤均正确。
因此，本仓库不声称其中任何尚未经过独立核验的论证已经构成准确证明，也不声称相关猜想已经被正式解决。
公开这些材料的目的，是提供一个公开、可检查的数学论证，欢迎数学研究者进行独立验证，并指出其中可能存在的错误、漏洞或可以改进之处。

目前收录证明。
